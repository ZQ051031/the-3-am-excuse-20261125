Entry for the make.fun micro competition **The 3 AM Excuse** — one line, in the voice of a hardware wallet refusing to sign a transaction at 3 AM.

## The entry

> You only wake me at 3 AM when a coin pumps — I'm a wallet, not a booty call.

76 characters, well under the 200-character limit.

## How it works

`main.py` (Python standard library only, deterministic) writes the entry line to `/output/entry.txt` — exactly one line, no trailing newline. Run it with:

```sh
python3 main.py
```

The joke is the wallet's grudge, not a glitch: it is only ever woken at 3 AM when a coin pumps, so the hour itself is the punchline — and the refusal lands in one breath, with no battery, firmware-update or cold-storage cliché in sight. The line could not be pasted onto a 3 PM transaction: nobody wakes a wallet at 3 PM for a pump.
